# Carousel anatomy — the 10-slide framework

Source: cross-confirmed by @marketingharry ("THE CAROUSEL ANATOMY") and @design.deb ("Carousel Framework"), 2026-05.

---

## The 5 phases

Every carousel passes through 5 phases. Map every slide to exactly one phase before you write copy.

```
HOOK → TRANSITION → TEASE → CLIMAX → ACTION
  1        2        3-7      8-9      10
```

| Phase | Slides | Function | What's on the slide |
|---|---|---|---|
| **HOOK** | 1 | Stop the scroll | One of the 42 archetypes. Two-tone headline. Optional hero photo with negative space. Persistent chrome only. |
| **TRANSITION** | 2 | Confirm the hook + push people in | "What user will gain" / "What they'll avoid" / "What makes them qualified to read this" |
| **TEASE** | 3-7 | Reveal info bit by bit | Examples, statistics, captivating visuals. Diagrams. Each slide unlocks one piece — never two. |
| **CLIMAX** | 8-9 | The "Aha" moment | The big reveal, lesson, quotable moment. Highest-saved slides in the deck. |
| **ACTION** | 10 | Make the next step obvious | Named CTA: "Comment STACK", "DM AUDIT", question close, manifesto. |

---

## The 3 slide types (slide-level discipline)

Every individual slide is one of exactly these three types. Never mix.

### 1. Hook slide
**Used on:** slides 1, 2.
**Body rule:** headline-dominant, minimal body. The headline carries the slide — no diagrams, no proof blocks, no pill payoffs.
**Density target:** ~80% headline, ~20% chrome/subhead.

### 2. Value slide
**Used on:** slides 3-9 (everything in TEASE + CLIMAX).
**Body rule:** "a little text + a lot of visuals." Diagram, photo, terminal block, comparison cards, data table, screenshot, mock IG post, quote with magenta border. Headline is short and supportive.
**Density target:** ~30% headline, ~50% visual proof, ~20% pill payoff + chrome.

### 3. CTA slide
**Used on:** slide 10 (or final slide of any deck length).
**Body rule:** image of you + 1 simple action. The image humanizes the ask. The action is named — "Comment STACK", "DM AUDIT", "Save it for later."
**Density target:** ~40% image of creator, ~40% headline + named ask, ~20% chrome.

## The squint test

Squint at the cover from arm's length (or zoom your screen to 25%).

- **Pass:** headline is readable, accent word is distinguishable from the rest, you can identify the topic in <1 second.
- **Fail:** headline blurs into a single tone, accent word disappears, topic is unclear.

Every cover must pass before you publish. If it fails — increase headline weight (go to 700-900), increase font size by 20%, OR raise contrast on the accent word.

## Deck length variants

| Length | When | Phase mapping |
|---|---|---|
| 5 slides | TikTok / fast skim | Hook · Transition · Tease · Climax · Action |
| 7 slides | Default IG / balanced | Hook · Transition · Tease×3 · Climax · Action |
| 10 slides | Save-optimized IG / educational | Hook · Transition · Tease×5 · Climax×2 · Action |
| 12 slides | LinkedIn document / deep dive | Hook · Transition · Tease×7 · Climax×2 · Action |

## Slide-by-slide function checklist

Run this before render. Every slide should answer "yes" to its row.

| Slide | Question |
|---|---|
| 1 | Does this stop the scroll in 1 second? Does it pass the squint test? |
| 2 | Does this confirm the promise from slide 1 with a concrete statement? |
| 3 | Am I revealing exactly ONE new thing? Is there a visual proof element? |
| 4 | Same as 3. Did I escalate the swipe cue? |
| 5 | Same as 3. Is the headline different in pattern (e.g., reframe vs step)? |
| 6 | Same as 3. Have I added a "save the post" prompt yet? (Optional save-bait slide.) |
| 7 | Same as 3. Am I building toward a climax, not just listing? |
| 8 | Is this the lesson/insight the whole deck has been building to? |
| 9 | Do I have proof — a screenshot, number, receipt, quote — that nails it? |
| 10 | Is the next step named, specific, and easy? Does it visually rhyme with slide 1? |

## Cross-reference: phase × layout × format

The three orthogonal dimensions:

```
PHASE    (HOOK / TRANSITION / TEASE / CLIMAX / ACTION) — slide function
LAYOUT   (Rahul / Harry / Sago / Terminal-mono / Photo-narrative) — visual personality
FORMAT   (Comparison / Tutorial / Native / Compilation / Story) — content type
```

A specific slide is the intersection of all three. E.g.:
- **TEASE phase + Terminal-mono layout + Tutorial format** → step block with terminal output proof
- **CLIMAX phase + Sago layout + Story format** → centered Playfair italic quote on charcoal
- **ACTION phase + Photo-narrative layout + Native format** → photo of you + headline overlay + named CTA

When briefing the skill, you don't need to specify all three explicitly — but the agent picks them all behind the scenes from your story type.
